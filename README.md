# Partnership Scout

One click gives a ranked outreach list of Product Hunt featured launches from the last 7 days
in four categories (project management, HR tech, developer productivity, team communication),
with a product-specific outreach angle written by Gemini Flash.

Status: work in progress (built stage by stage). Full setup, how it works and known
limitations will be added in the final stage.

Setup: copy `.env.example` to `.env.local`, fill in the values, then `npm install` and `npm run dev`.
